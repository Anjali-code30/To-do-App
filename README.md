<h1> To-do-App</h1>

<p>A simple to-do list app built with HTML, CSS, and JavaScript. Add tasks, mark them as complete, and remove them when you're done — all saved to your browser's local storage so your list stays put even after you refresh.</p>

<h2>Features</h2>

<li>Add tasks – type a task and add it to your list</li>
<li>Check/uncheck tasks – click a task to mark it complete or mark it incomplete again</li>
<li>Remove tasks – delete tasks you no longer need</li>
<li>Persistent storage – tasks are saved in the browser's local storage, so your list is still there when you come back</li>


<h2>Tech Stack</h2>

<li>HTML</li>
<li>CSS</li>
<li>JavaScript (DOM manipulation, local storage)</li>
